# Битола

Жива, илустрирана 3Д мапа на Битола во прелистувач, изградена од отворени податоци.
Статичен сајт: three.js + Vite.

**Мапата:** https://aleksandar-transformian.github.io/bitola-map/

- Стилови: „Разгледница“ (акварел), „Макета“ (архитектонска макета) — смена во живо
- 30 знаменитости, натписи на кирилица, „Оди до…“, ден / зајдисонце / ноќ
- Глувче, допир и тастатура (упатство со „?“ во менито)

Развој: види `CLAUDE.md` (команди, архитектура) и `docs/` (спецификација, белешки).

```bash
npm install
npm run dev
```

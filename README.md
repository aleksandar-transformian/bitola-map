# Битола

Жива, илустрирана 3Д мапа на Битола во прелистувач, изградена од отворени податоци.
Статичен сајт: three.js + Vite.

**Мапата:** https://aleksandar-transformian.github.io/bitola-map/

## Што има

- **Пет стилови**, смена во живо: „Разгледница“ (акварел на хартија), „Макета“ (архитектонска
  макета), „Цртан филм“, „Low-poly“, „Бајка“ (зимска минијатура).
- **Ден / зајдисонце / ноќ** за секој стил — ноќе светат прозорците, улиците и светилките.
- **Снег**: без снег / снег / снежи.
- **31 знаменитост**, моделирана според OSM и фотографии: Саат Кула, Јени и Ајдар-кади џамија,
  Безистен, Широк Сокак, Магнолија со споменикот на Филип II, Хераклеа, Битолскиот филџан и др.
- **Живот на мапата**: автомобили и пешаци (може да се исклучи).
- **„Оди до…“** — лет до знаменитост; натписи на кирилица; **„Зачувај слика“** (PNG).
- 20 500 згради (OpenStreetMap + Microsoft ML Buildings) на вистински релјеф до падините на Пелистер.

## Контроли

| | |
|---|---|
| Глувче | лево влечење — поместување · десно влечење — ротација/наклон · тркалце — зум |
| Допир | еден прст — поместување · два прста — зум и ротација |
| Тастатура | стрелки · `Q`/`E` ротација · `+`/`−` зум · `PgUp`/`PgDn` наклон · `Home` преглед · `1`–`5` стил · `S` снег · `?` помош |

Линкови со поглед: `#style=maketa&time=night&view=shirok-sokak` (стил, време, `weather=snow`, поглед).
Мерење: `?debug` (FPS во живо), `?bench` (бенчмарк).

Развој: види `CLAUDE.md` (команди, архитектура) и `docs/` (спецификација, белешки).

```bash
npm install
npm run dev
```

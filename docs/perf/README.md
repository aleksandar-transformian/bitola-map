# Мерења на изведбата

- `baseline-swiftshader.json` — основа за структурата на кадарот (повици, триаголници) на десктоп
  профилот, headless SwiftShader 720×450. `npm run bench` секогаш се споредува со неа;
  `--check` враќа грешка при регресија > 10 %. Се обновува свесно, по оптимизација или по
  одобрено додавање на содржина (копирај го новиот извештај врз неа).
- `baseline-swiftshader-mobile.json` — истото за телефонскиот профил (`--mobile`).
- `results/` — извештаи од мерењата. Имиња: `<датум>-<commit>-<серија>-<swiftshader|gpu>[-mobile].json`.
  **Мерењата од вистински уред (`-gpu`) се единствените со веродостојни времиња.**

Како се мери на референтниот уред (MacBook Pro 2018, Radeon Pro 555X): `docs/specs/002-performance/plan.md`
→ „Протокол за мерење на референтниот уред“. Накратко:

1. `npm run dev`, во Chrome отвори `http://127.0.0.1:5173/?bench` (прозорец преку цел екран, ~3 мин).
2. „Сними JSON“ → стави го во `results/`.
3. Споредба: `node scripts/dev/bench.mjs --compare results/стар.json results/нов.json`.

Во живо: `?debug` покажува кадар p50/p95, CPU по фаза и GPU по пас.

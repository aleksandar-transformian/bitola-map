# Технички план

## Податочен тек

```
Overpass API ──(GitHub Actions: data-fetch.yml)──► data/raw/osm.json.gz   (комитуван)
AWS Terrain Tiles (Terrarium, z14) ──────────────► data/cache/terrain/*.png (кеш)
                     │
                     ▼  scripts/data/build.mjs
public/data/  terrain.bin  buildings.bin  roads.bin  lines.bin  areas.bin  trees.bin
              pois.json  meta.json                                        (комитувани)
                     │
                     ▼  прелистувач (src/data/loader.js + src/world/*)
геометрија во меморија: релјеф, подлога (canvas), ленти, згради
```

## Формат `.bin`

`src/lib/pack.js`: `"BTM1"` + должина + JSON заглавје (`meta`, список на низи) + типизирани
низи порамнети на 8 B. Координати Int16 × 0.25 m во локалниот систем (x = исток, z = југ).
Полигоните: `polyRing` (индекс на прв прстен по полигон) → `ringPt` (индекс на прва точка по
прстен) → `coords`. Полилиниите: `linePt` → `coords`. Атрибутите се паралелни низи по објект.

## Слоеви на сцената

| слој | геометрија | зависи од стил преку |
|---|---|---|
| небо | сфера со градиент | uniforms |
| релјеф | мрежа (stride 1/2) + бочни страни | материјал, текстура на подлогата |
| подлога | canvas → CanvasTexture | `paint(style)` |
| улици / пруга / вода | ленти (ribbons) по релјефот | вертекс бои (`recolor`) |
| згради | една споена геометрија, групи ѕид/покрив | вертекс бои (`recolor`), материјали |
| светла / магла | DirectionalLight (сенки) + HemisphereLight | параметри |

## Систем за стилови (спроведен во фаза 2)

Интерфејсот е опишан во `src/styles/index.js`. Секој стил е податочен објект + неколку функции:

```js
// src/styles/<id>.js
export default {
  id, name, tagline, swatch,             // „razglednica“, „Разгледница“, …
  geometry: { roofs: 'flat' | 'gabled' },
  ground: { painter: 'flat' | 'watercolor', base, areas: {...}, washes?, outline? },
  roads: {...}, rail: [..], water, buildings: { класа: [ѕид, покрив], roofAlt?, variation, ao },
  sky, fog, light: { sun, hemi, shadow, toneMapping, exposure }, ui: { paper },
  materials(ctx) → { terrain, skirt, walls, roofs, roads, rail, water },
  post(ctx)?     → { before: Pass[], after: Pass[] },   // before = HDR (AO, DOF), after = sRGB (хартија)
  update(ctx, post)?                                     // по кадар (фокус на DOF, радиус на AO)
};
```

`src/styles/manager.js` при смена: (1) снимка на тековниот кадар во `#fade` за претопување;
(2) ако `geometry.roofs` се разликува — нова геометрија на зградите (кеш на десктоп) и анимација
„растење“; (3) нови материјали (додатоци: `withGrow`, `withContours`, `withLayers`), старите се
ослободуваат; (4) бои по теме и ново цртање на подлогата; (5) светла, магла, небо, tone mapping;
(6) нови пост-пасови; (7) тема на интерфејсот преку `html[data-style]`.

## Содржина (фаза 3)

- **Знаменитости**: `config/landmarks.js` → `build.mjs` (основи, подлога) → `landmarks.json` →
  `world/landmarks/models.js`. Секој модел добива рамка од OBB на основата (u = долга оска) и гради
  од примитиви (`Kit`): кутии, цилиндри, куполи, двоводни и четиристрешни покриви, плочи по
  полигон, прозорци по ѕидови. Бојата е по „дел“ (`PARTS`) од `style.landmarks`.
- **Натписи**: HTML над canvas-от, проекција секој кадар, видливост по вид и зум, алчно
  одбегнување на преклопување (по ранг) и на панелите на интерфејсот.
- **Време од денот**: тежини `{day, sunset, night}` со премин од 1.6 s; `resolveLighting` ги меша
  поставките (бои во линеарен простор). `env.night` ги пали ноќните ефекти во шејдерите.
- **Дрвја**: `build.mjs` полни паркови/гробишта/шуми/овоштарници со растресена мрежа (без згради),
  поблиските до центарот имаат предност (граница 40 000); телефонот црта секое трето.

## Фаза 4 — план

Редослед: 4.1 → 4.7. По секој чекор: screenshot-ови (сите стилови × ден/ноќ), `check-styles.mjs`,
бројки во NOTES, спојување во `develop`. Пред 4.7 — преглед од сопственикот.

### 4.1 „Цртан филм“ (`styles/crtan.js`)
- **Изглед:** чисти, заситени бои (жолто-портокалови фасади, црвени покриви, тревно зелено,
  светло сина вода); сенчење во 3 тона (`MeshToonMaterial` + градиент од 3 пиксели) наместо меко
  осветлување; темни контури на зградите и знаменитостите; дебели контури на парковите, реките и
  улиците во подлогата (canvas — бесплатно во рендерирање); тркалезни дрвја-топчиња; коси покриви;
  натписи во „балончиња“ со заоблени рабови и дебел фонт.
- **Лесен:** без сенки, без амбиентна оклузија, без пост-процесирање, без нови податоци или
  текстури (градиентот е 3 пиксели). Контурите се „inverted hull“ (втора, малку надуена геометрија
  со задни страни, една боја) само за зградите и знаменитостите; на телефон може да се исклучат.
- **Цел:** поевтин од „Разгледница“ — без пасот за сенки и пасот за хартија; ≤ 1.3× нејзините
  триаголници во кадар со контурите, ≤ 0.7× без нив. Добар кандидат за стандарден стил на телефон.
- Ден/зајдисонце/ноќ работат автоматски (ноќе: топли прозорци и улици, како кај другите).

### 4.2 „Low-poly“ (`styles/lowpoly.js`)
- Фасетирано: рамно сенчење (`flatShading`), теренот во поголеми триаголници, нова варијанта на
  покривите `'hip'` (четиристрешни/пирамидални), дрвја-конуси (`geometry.trees: 'cone'`).
- Модерна, пригушена палета (пастели + теракота); без пост-процесирање; сенки само на десктоп.
- Најлесниот стил: телефон без сенки, помалку дрвја.

### 4.3 „Ноќна Битола“ (`styles/nokna.js`)
- Стилот е секогаш ноќ (копчињата за време се оневозможуваат додека е избран): темна, речиси
  црна подлога, улиците светат по класа (Широк Сокак и плоштадите најмногу), повеќе осветлени
  прозорци, осветлени знаменитости (рефлектори), ѕвезди.
- Десктоп: `UnrealBloomPass` за сјај на светлата; телефон: без bloom (адитивните светилки го даваат
  ефектот).

### 4.4 Сообраќај и пешаци (`world/traffic.js`)
- Автомобили: инстанцирани кутии (2 бои по стил) што возат по улиците од примарни до станбени,
  брзина по класа, свртување на раскрсниците по случаен избор; ноќе фарови и стоп-светла.
  ~400 на десктоп / ~150 на телефон.
- Пешаци: инстанцирани фигури по Широк Сокак, Магнолија и плоштадите (~250 / ~100), бавно
  одење со мало нишање.
- Анимација на CPU со ажурирање на инстанците (< 1 ms по кадар); вклучи/исклучи во менито
  („Живот на мапата“), запаметено.

### 4.5 „Зачувај слика“
- Копче во менито: кадар со 2× резолуција (телефон 1×), со насловот „Битола“ и атрибуцијата
  вградени долу (ODbL бара видлива атрибуција), без копчињата; `bitola-<стил>-<време>.png`.

### 4.6 Мобилна оптимизација
- Автоматско олеснување: ако FPS < 30 повеќе од 3 s → помал pixel ratio, без tilt-shift/контури,
  помалку дрвја; обратно ако има резерва. Приказ во `?debug`.
- Меморија: ослободување на кешот на геометријата на телефон (веќе), граница за текстурата,
  проверка дека нема протекување при смена на стил (`renderer.info.memory`).
- **Мерење на вистински уред:** сопственикот го отвора сајтот (по 4.7 или преку локална мрежа) со
  `?debug` на телефон и ги праќа FPS/времињата — headless тестовите тука не помагаат.

### 4.7 Објава
- `.github/workflows/deploy.yml`: build + `actions/upload-pages-artifact` + `actions/deploy-pages`
  при push на `main`; во Settings → Pages изворот треба да е „GitHub Actions“ (го вклучува
  сопственикот).
- LICENSE (MIT за кодот; податоците остануваат ODbL) — само по потврда.

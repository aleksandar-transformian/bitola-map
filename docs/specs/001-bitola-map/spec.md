# Спецификација: „Битола“ — жива, илустрирана 3Д мапа

Статус: одобрена (барање од сопственикот, 2026-11-11) · Завршени фази: 1, 2

## Цел

Статичен веб-сајт (без backend), објавен на GitHub Pages, што ја прикажува Битола со околината
како интерактивна 3Д мапа во прелистувач, изградена од отворени податоци, со повеќе визуелни
стилови што се менуваат во живо.

## Опфат

- Градот Битола со сите населби, Лавци, Тумбе Кафе, Хераклеа и почетокот на падините кон
  Пелистер. Границите се во еден конфигурациски фајл (`src/config/region.js`).

## Функционални барања

| ID | Барање |
|---|---|
| F1 | Релјеф од AWS Terrain Tiles (Terrarium); згради на вистински релјеф. |
| F2 | Згради од OSM, дополнети со Overture Maps (Microsoft ML Buildings, ODbL) каде што OSM нема; висина од `height`/`building:levels`, инаку проценка по облик, класа и населба (стара чаршија и Широк Сокак ниски 2–3 ката, станбени блокови повисоки, периферија куќи). |
| F3 | Улици, железница, landuse, паркови, вода (Драгор), дрвја, стадион. |
| F4 | Повеќе визуелни стилови со смена во живо, без превчитување; стилот е посебен слој од податоците/геометријата; секој стил е модул `styles/<име>.js` со јасен интерфејс. |
| F5 | Стил што бара друга геометрија ги пресоздава само засегнатите делови, со кратка анимација на премин. |
| F6 | Изборот на стил се памти (localStorage во try/catch) и се дели преку URL (`#style=…`). |
| F7 | Почетни стилови: „Разгледница“, „Макета“, „Ноќна Битола“, „Low-poly“. |
| F8 | Рачно моделирани знаменитости: Саат кула, Јени џамија, Ајдар-кади џамија, Безистен, Офицерски дом, Широк Сокак со фасадите, Магнолија плоштад, Св. Димитрија, Хераклеа Линкестис. |
| F9 | Ден / зајдисонце / ноќ; по можност сообраќај и пешаци (посебно Широк Сокак). |
| F10 | Брзи погледи: Широк Сокак, Чаршија, Градски парк, Хераклеа, Преглед. |
| F11 | Кирилични натписи за населби и знаменитости. |
| F12 | Контроли: глувче, допир, тастатура. |
| F13 | Мобилна верзија со полесен профил (меморија на iOS). |
| F14 | Копче „Зачувај слика“ (PNG). |
| F15 | UI на македонски со правилен правопис; наслов „Битола“. |
| F16 | Видлива атрибуција „© соработниците на OpenStreetMap“ (ODbL), и на телефон; кредит за Overture Maps / Microsoft и Terrain Tiles. |

## Нефункционални барања

| ID | Барање |
|---|---|
| N1 | three.js (WebGL) + Vite, чист JavaScript (ES модули), без framework. |
| N2 | Node скрипти ги симнуваат и обработуваат податоците во компактни фајлови во `public/`, кои се комитуваат (свеж clone работи без симнување). |
| N3 | Deploy: GitHub Actions → GitHub Pages при push на `main`. |
| N4 | Оригинална работа: без копирање код, шејдери, текстови или дизајн од проекти без лиценца. |
| N5 | Визуелна верификација со headless прелистувач по секоја поголема промена; мерење време на вчитување и FPS. |
| N6 | `CLAUDE.md` и `docs/NOTES.md` се одржуваат за продолжување во секоја сесија. |
| N7 | Лиценца: MIT за кодот (податоците остануваат ODbL) — по потврда од сопственикот. |

## Критериуми за прифаќање по фази

1. **Скелет и податоци** — `npm run data` ги произведува `public/data/*`; `npm run dev` прикажува
   релјеф + згради + улици во еден стил; атрибуцијата е видлива; screenshot-ови и мерења во NOTES.
2. **Систем за стилови** — интерфејс за стил, „Разгледница“ и „Макета“, смена во живо, памтење и
   `#style=`.
3. **Содржина** — знаменитости, натписи, брзи погледи, ден/зајдисонце/ноќ.
4. **Завршување** — „Ноќна Битола“, „Low-poly“, сообраќај, мобилна оптимизација, deploy.

Секоја фаза завршува со преглед од сопственикот пред следната.
